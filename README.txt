HLUBI TEST MARKETPLACE — SELLER REVIEW UPDATE

Files:
- index.html
- styles.css
- app.js

Prototype features added:
- Seller registration is free during testing.
- Seller applications start as PENDING.
- The first submitted product starts as PENDING.
- Owner Review section lets the owner approve/reject seller applications.
- A product can only be approved after its seller is approved.
- Approved products appear in Featured Products; rejected/pending products stay hidden.
- Sample catalogue products remain visible for testing.

IMPORTANT LIMITATIONS:
This is a front-end demo. Applications and review decisions are stored in localStorage in the current browser only. They do not sync between different visitors/devices and the owner review panel has no secure login. Do not use it for real seller onboarding or sensitive information until a real database, authentication, and server-side permissions are added.

Deploy:
Upload the three website files (index.html, styles.css, app.js) to the GitHub repository root. Once the Netlify site is linked to this repository, commit/push changes to trigger a deployment. Alternatively, deploy the folder manually to Netlify for a quick test.
